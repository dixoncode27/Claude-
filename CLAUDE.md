## Development Branch

Active development happens on feature branches. The default workflow is:
- Create a branch for each feature or task
- Commit changes with descriptive messages
- Push to `origin/<branch-name>` using `git push -u origin <branch-name>`

## Git Conventions

- Use clear, descriptive commit messages that explain the *why* of the change
- Never force-push without explicit user confirmation
- Never skip pre-commit hooks (`--no-verify`)
